# 🐝 BeeltyMine

**BeeltyMine** is an **enhanced and strengthened fork of [PocketMine-MP](https://github.com/pmmp/PocketMine-MP)** — focused on fixing issues, adding missing features, and improving overall performance and stability.  
It’s built to provide a smoother gameplay experience with better plugin support and additional vanilla-like content while staying fully compatible with existing PocketMine-MP plugins.

---

## ⚙️ Highlights
- 🚀 **Improved performance and stability** for smoother gameplay  
- 🧠 **Reduced memory usage** and faster tick handling  
- 🔧 **Enhanced plugin & API compatibility**  
- 💪 **Fixed many bugs** from the original PocketMine-MP  
- 🧱 **Added missing vanilla blocks and entities** such as ArmorStand, Beehive, and Shelf  
- 🧥 **Fixed skin and cape rendering issues**

---

## ⚠️ Note
BeeltyMine (like PocketMine-MP) is **not** a vanilla Minecraft server.  
Some vanilla features such as **full Redstone logic**, **mob AI**, and **terrain generation** are still in progress or intentionally excluded for performance reasons.

For a full vanilla experience, use the [official Bedrock server software](https://minecraft.net/download/server/bedrock).
